# SisaBaik API

REST API aplikasi SisaBaik untuk mengelola penawaran makanan berlebih dan pemesanan menggunakan Express.js dan PostgreSQL.

## 1. Teknologi
- Node.js 22 atau lebih baru
- Express.js 5
- PostgreSQL
- JWT untuk autentikasi
- bcryptjs untuk hashing kata sandi
- express-rate-limit untuk pembatasan percobaan autentikasi
- Helmet untuk keamanan HTTP

## 2. Persyaratan
- Node.js versi 22 atau lebih baru.
- PostgreSQL.
- Database pengembangan `sisabaik_dev`.
